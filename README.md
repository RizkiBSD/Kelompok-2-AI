# Kelompok 2 — AI

Repositori proyek kelompok untuk mata kuliah / topik **Artificial Intelligence**.

## Tentang

Repositori ini digunakan sebagai tempat kolaborasi Kelompok 2 untuk menyimpan
kode, dataset, laporan, dan dokumentasi proyek.

## Struktur Repositori

```
.
├── README.md
├── .gitignore
└── (kode & dokumentasi proyek)
```

## Persyaratan

Sesuaikan bagian ini dengan kebutuhan proyek:

- Python 3.10+ _(jika menggunakan Python)_
- Node.js 18+ _(jika menggunakan JavaScript/TypeScript)_
- Git

## Cara Menjalankan

```bash
# clone repositori
git clone https://github.com/RizkiBSD/Kelompok-2-AI.git
cd Kelompok-2-AI

# instal dependensi sesuai stack yang dipakai
# pip install -r requirements.txt
# npm install
```

## Alur Kontribusi

1. Buat branch baru dari `main`
   ```bash
   git checkout -b fitur/nama-fitur
   ```
2. Lakukan perubahan, lalu commit
   ```bash
   git add .
   git commit -m "menambahkan fitur X"
   ```
3. Push branch dan buka Pull Request
   ```bash
   git push -u origin fitur/nama-fitur
   ```
